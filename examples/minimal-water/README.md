# minimal-water：最小的水文过程算例

**用途**：用 10 天、单元素、单层的数据，验证淋溶、径流（溶解态）、侵蚀（颗粒态）
与 `schema_version = 5` 的水量诊断列。

**这不是任何田块的预测值。** 它的输入是刻意构造的：没有沉降、施肥与灌溉，
只有输出过程，因此储量必然下降。所有参数都在下文标明是“示例假设”还是“借用来源”。

---

## 1. 与 `examples/minimal` 的区别

| | `minimal` | `minimal-water` |
|---|---|---|
| 目的 | 验证输入过程与列契约 | 验证三个水文输出过程与水量列 |
| 过程 | 沉降/施肥/灌溉/收获/秸秆 | 淋溶 + 径流（溶解态）+ 侵蚀（颗粒态） |
| 气象 | 无 | 有（降水 + 蒸散） |
| 输出趋势 | 储量不变或上升 | 储量下降（预期） |

## 4. 输入假设（每条都要能追溯）

| 输入 | 取值 | 性质 | 说明 |
|---|---|---|---|
| 降水 / 蒸散 | 10 / 4 mm·d⁻¹（前 8 天） | **示例构造** | 只为让盈余 = 6 mm·d⁻¹；第 9–10 天 P=0 |
| `hydrology.runoff_fraction` | 0.5 | **示例构造** | 中国农田没有可引用的通用径流系数（ADR-0012） |
| `kd.Cd` | 300 L·kg⁻¹ | **示例构造** | 全量口径；随土壤可差 10–100 倍，不可当默认值 |
| `erosion.rate` | 1.07 t·ha⁻¹·a⁻¹ | **借用文献值** | 浙江红壤 8–15° 等高耕作，`PARAMS_SOURCE.md` §5.4 |
| `erosion.er.Cd` | 1.0 | **保守假设** | Cd 无中国实测 ER；3.98 是 Cr/Cu/Pb/Ni 通用值 |

参数库中的 `source` 字段逐条写明了上述性质。**这些数值不是文献默认值，也不会进入 `src/`。**

## 5. 手算复核（第 1 天）

土壤质量：`1300 kg·m⁻³ × 0.2 m = 260 kg·m⁻²`；初始储量 `0.35 × 260 = 91 mg·m⁻²`。

```text
盈余   = max(0, P + I − ET) = max(0, 10 + 0 − 4) = 6 mm/d
径流   = 0.5 × 6 = 3 mm/d
下渗   = 6 − 3 = 3 mm/d

C_sol  = C_total / Kd = 0.35 / 300 = 1.1666667e-3 mg/L
淋溶   = 3 × 1.1666667e-3 = 0.0035 mg·m⁻²·d⁻¹
径流   = 3 × 1.1666667e-3 = 0.0035 mg·m⁻²·d⁻¹
侵蚀   = (1.07 × 0.1 / 365) × 1.0 × 0.35 = 1.0260274e-4 mg·m⁻²·d⁻¹
输出合计 = 0.0071026027 mg·m⁻²·d⁻¹

第 1 天末含量 = 0.35 − 0.0071026027 / 260 = 0.3499726823 mg/kg
```

第 9 天：`P=0, ET=4` → 盈余为 0 → 径流与淋溶都为 0；但侵蚀按年速率继续
（`1.0253869e-4 mg·m⁻²·d⁻¹`），因为侵蚀不依赖当日水量。

10 天汇总：

```text
期末储量     90.94298962053512 mg/m²
期末含量     0.3497807293 mg/kg
累积输出     0.0570104 mg/m²
闭合残差     1e-14 mg/m²（相对 ~1e-16）
```

## 6. 三个必须注意的口径

1. **`runoff` 与 `erosion` 不能相加**：前者是溶解态，后者是颗粒态；
   把它们加在一起会得到“双计”的径流总输出（ADR-0012）。
2. **水量列可直接对账**：`water_runoff_mm_d + water_percolation_mm_d`
   等于当日 `降水 + 灌溉 − 蒸散`（不小于 0）。
3. **参数没有默认值**：把 `defaults/params.yaml` 换成自己的实测值，
   比改 `src/` 更安全；缺失参数会直接报错，不会静默取 0。

---

## 7. 改成自己的算例

1. 用本地气象替换 `weather.csv`（列名与单位可在 `model.yaml` 中改）；
2. 把 `runoff_fraction` 换成实测径流系数，并在报告中写明来源与时段；
3. 用本地土壤的 `kd.<元素>`（并声明 `kd_basis`）替换示例值；
4. 侵蚀速率按区域取：稻田 1–6 t·ha⁻¹·a⁻¹，**不要**套用黄土高原 68–126；
5. 若只做淋溶：删除 `runoff` / `erosion` 块与 `hydrology`，下渗量会变成降水盈余全量（上限）。
